# Мышцы и функции — тренажёр по функциональной анатомии

Тренажёр для подготовки к экзамену: атлас мышц, тест с вариантами, свободный ответ, карточки с интервальным повторением и анализ асан (укорочена / растянута).

Материал — по презентации «Функциональная анатомия мышечной системы, ИВМР 2025».

## Как опубликовать на GitHub Pages

1. Войдите на github.com и нажмите **New repository** (зелёная кнопка или «+» вверху справа).
2. Название, например, `muscle-trainer`. Тип — **Public**. Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое папки** (файлы `index.html`, `app.js`, `data.js`, `style.css`, `README.md` и папку `img`). Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите *Source: Deploy from a branch*, ветку **main** и папку **/ (root)**. Нажмите **Save**.
6. Через 1–2 минуты сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/muscle-trainer/`. Эту ссылку можно отправлять друзьям.

## Как править

Все тексты мышц лежат в файле **`data.js`**. Чтобы исправить:

1. Откройте `data.js` на GitHub и нажмите значок карандаша (**Edit this file**).
2. Найдите мышцу (Ctrl+F / Cmd+F по названию) и поменяйте текст **внутри кавычек**.
3. Нажмите **Commit changes**. Через минуту сайт обновится (иногда нужно обновить страницу с Ctrl+Shift+R).

Что где:

- `origin: { t: "…" }` — начало
- `insertion: { t: "…" }` — прикрепление
- `functions: [ { t: "…" }, … ]` — функции
- `notes: [ "…" ]` — заметки «Важно»
- `k: [ … ]` и `fk: [ … ]` — ключевые слова для режима «Вписать ответ». Формат: `"Подпись=основа1|основа2"`. Ответ засчитывается, если в нём есть хотя бы одна из основ. Основы пишите без окончаний, например `подвздош` найдёт «подвздошный», «подвздошная» и т. д.
- `a: [ { j: "ТБС", m: "сгибание" } ]` внутри функции — для режима «Асаны»: сустав и движение.
- `img: [ { src: "img/файл.jpg" } ]` — картинки. Новую картинку загрузите в папку `img` (Add file → Upload files) и укажите её имя.

Если после правки страница стала пустой — скорее всего, пропала запятая или кавычка. Откройте файл → **History** и верните предыдущую версию, или сравните с соседней мышцей.

Прогресс (результаты тестов, карточки) хранится в браузере каждого пользователя и никуда не отправляется.
